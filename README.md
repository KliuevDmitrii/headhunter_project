# Подборка вакансий HH → Telegram

Python 3.11. Поиск вакансий использует публичный API HH: OAuth-токен для
подборки не требуется. Параметры поиска и исключения находятся в `config.ini`.

## Запуск

Установите зависимости: `python -m pip install -r requirements.txt`.
Задайте переменные окружения `TG_BOT_TOKEN` и `TG_CHAT_ID` через защищённые
настройки среды. Код читает окружение процесса; `.env` автоматически не загружается.

Из корня репозитория:

```sh
python -m unittest discover -s tests -v  # без внешних запросов и сообщений
python -m hh_bump.collect              # собирает отчёт и отправляет его в Telegram
```

Сообщение с HTML-отчётом отправляется как документ с подписью. Поиск обходит
ключи и регионы по страницам, останавливается на конце выдачи и соблюдает
`max_searches_per_run`, включая неудачные попытки. Пустая выдача отличается
от ошибки API; при частичной выдаче отправляется предупреждение, а запуск
завершается с ошибкой. Временные сетевые ошибки HH повторяются до двух раз;
403/429 останавливают дальнейший поиск. Отправка Telegram ограничена таймаутом
и автоматически не повторяется, чтобы не создавать дубликаты.

## Если подборки перестали приходить

1. Откройте [HH Collect Vacancies в Actions](https://github.com/KliuevDmitrii/headhunter_project/actions/workflows/hh_collect_vacancies.yml).
   GitHub отключает расписание публичных репозиториев после 60 дней без активности.
   Если показана кнопка **Enable workflow**, включите workflow. Изменения кода
   должны попасть в `master`, чтобы использоваться расписанием.
2. Проверьте `TG_BOT_TOKEN` и `TG_CHAT_ID` в **Settings → Secrets and variables → Actions**.
   Бот должен иметь возможность писать в выбранный чат.
3. **Run workflow** запускает сбор и реальную отправку. В журнале будут указаны
   ошибки HH или Telegram, включая неверный чат/заблокированного бота.
   Если отчёт построен, но Telegram недоступен, HTML остаётся в артефакте
   `vacancies-report` на странице запуска в течение 7 дней.

Расписание подборки: понедельник–пятница, 17:00 по Тбилиси (13:00 UTC).
GitHub Actions может задерживать запуск по расписанию. Постоянный процесс
в облачной среде не нужен.

`hh_bump.main` и workflow **HH Resume Bump** отправляют напоминание в Telegram;
они не поднимают резюме автоматически.
